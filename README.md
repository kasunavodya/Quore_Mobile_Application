# Quore – Quotes Mobile Application

Quore is a mobile application developed as a university academic project using Flutter and Firebase. It allows users to explore, add, and manage inspirational quotes from different people and categories.

## Features

- View inspirational quotes.
- Add new quotes with categories and images.
- Update and delete quotes (Admin).
- Browse quotes by people.
- Explore personal quotes.
- Browse quotes by categories.
- View quotes with associated images.

## Technologies Used

- Flutter
- Dart
- Firebase

## Project Information

- **Project Type:** University Academic Project
- **Platform:** Android Mobile Application
- **Framework:** Flutter
